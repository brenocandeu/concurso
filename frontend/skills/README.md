## 📂 Estrutura de Pastas

### 1️⃣ `01-planejamento/`
* **`grill-me`**: Faz uma entrevista técnica passo a passo sobre uma ideia ou tela antes de escrever código, percorrendo cada decisão de arquitetura/UX e sugerindo a melhor resposta.

### 2️⃣ `02-direcao-visual/`
* **`frontend-design`** *(Anthropic)*: Direção de arte para criar interfaces com identidade visual própria, evitando clichês de "site gerado por IA", escolhendo tipografia, escala e cores intencionais.

### 3️⃣ `03-auditoria-ux/`
* **`web-design-guidelines`** *(Vercel)*: Audita componentes e páginas contra o guia oficial de interfaces da Vercel (acessibilidade, foco, teclado, formulários, estados de loading e UX).

### 4️⃣ `04-conversao-e-produto/`
* **`revenue-centric-design`** *(134 princípios)*: Playbook de produto, CRO e ciência comportamental para melhorar conversão em Landing Pages, Onboarding, Checkout, Pricing, Dashboards e Retenção.

### 5️⃣ `05-animacoes-e-ui-engineering/` *(Pacote Emil Kowalski)*
* **`emil-design-eng`**: Guia principal de engenharia de design e polimento de UI.
* **`animate`**: Cria animações do zero escolhendo a curva (`easing`), duração e propriedades corretas.
* **`animate-expo`**: Animações fluidas focadas em React Native / Expo.
* **`review-animations`**: Revisa animações existentes aplicando regras estritas de fluidez.
* **`improve-animations`**: Audita todas as animações do projeto e gera correções priorizadas.
* **`find-animation-opportunities`**: Analisa uma tela e aponta onde faz sentido adicionar micro-interações (e onde não animar).
* **`animation-performance`**: Corrige animações que estão travando ou perdendo frames (60fps).
* **`animation-vocabulary`**: Glossário técnico para descrever exatamente o efeito visual desejado para a IA.
* **`apple-design`**: Princípios de design e movimento fluido da Apple (WWDC) adaptados para a Web.
* **`mobile-native`**: Deixa a aplicação web com sensação de app nativo no celular (`100vh`, zoom em inputs no iOS, safe areas, toque sem delay).
* **`break-ui`**: Testa a interface contra dados extremos (nomes gigantes, listas vazias, números enormes) para evitar quebras de layout.
* **`prototype`**: Cria múltiplas variações de um mesmo componente ou tela com um seletor rápido para comparar.
* **`pick-ui-library`**: Ajuda a escolher a biblioteca certa de UI para cada problema (em vez de recriar componentes complexos do zero).
* **`ask-sonner`**: Guia completo de configuração, estilização e receitas para notificações toast com `sonner`.
* **`write-swift`**: Boas práticas modernas de Swift (caso haja app iOS futuro).
